# Orca Music Player (虎鲸笔记原生音乐播放器插件)

专为 [虎鲸笔记 (Orca Note)](https://github.com/sethyuan/orca-note) 打造的内置常驻音乐播放器插件。

## ✨ 特色亮点

- 🎵 **多平台音乐聚合**：自动识别笔记中收藏的 **网易云音乐**、**哔哩哔哩 (B站)** 以及 **YouTube** 音乐视频条目。
- ⚡ **原生常驻伴播**：作为虎鲸笔记原生插件运行，无需借助外部浏览器后台网页，记笔记、写日记时背景音乐不间断。
- 📜 **歌单与状态管理**：
  - 自动扫描解析库中带有 `#音乐` 标签的笔记块；
  - 支持 **顺序播放**、**随机播放** 与 **单曲循环**；
  - 播放清单快速切换与实时高亮。
- 🎛 **轻量悬浮挂载与折叠**：
  - 支持右下角悬浮胶囊迷你模式（带唱片旋转动效）；
  - 支持顶部栏（Headbar）一键呼出与折叠完整播放器面板；
  - 注册原生命令（`音乐: 播放/暂停`、`下一首`、`上一首`）。
- 🧩 **高内聚模块化设计**：遵循模块化工程规范，各模块职责明确，单文件代码量均控制在 200 行以内。

## 📦 安装使用方式

1. 编译输出插件文件：
   ```bash
   npm install --legacy-peer-deps
   npm run build
   ```
2. 将本仓库目录整体放置于虎鲸笔记插件目录 `orca/plugins/orca-music-player`；
3. 在虎鲸笔记的设置 -> 插件列表中启用 **Orca Music Player** 即可！
